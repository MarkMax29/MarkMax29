### 🔐 ESP32 Smart Security System

A complete **embedded security system** built around an ESP32, combining sensors, physical access control and a real-time web dashboard.

Features include **PIR motion detection, door monitoring, PIN authentication, OLED interface, servo locking, alarm states and live WiFi/WebSocket communication**.

The firmware uses a **7-state finite state machine** and non-blocking logic to simultaneously manage hardware and network communication.

**Tech:** `ESP32` `C++` `PlatformIO` `WiFi` `WebSocket` `IoT` `HTML` `JavaScript`
