# MarkMax29 Digital Constellation — setup

1. Upload `assets/constellation.svg` to your `MarkMax29/MarkMax29` repository.
2. Replace the repository's `README.md` with the README from this package.
3. Commit the changes.
4. Open `https://github.com/MarkMax29` to see the animation.

## Clean up the previous Contribution Run experiment
You can delete these old files if they are still in the repository:
- `.github/workflows/contribution-run.yml`
- `scripts/generate_contribution_run.py`
- `assets/contribution-run.svg`

The constellation animation is pure SVG and does not need GitHub Actions or JavaScript.
